# QuickPaste 快捷粘贴工具 - 使用说明

## 这是什么？

QuickPaste 是一个 Windows 快捷粘贴工具。你预先设置好常用的文本内容和对应的快捷键，之后在任何地方按下快捷键，预设的文本就会自动粘贴到光标位置——**只需按一次快捷键，不需要再按 Ctrl+V**。

## 快速上手

1. 双击运行 `QuickPaste.exe`
2. 界面上已有两条示例预设，点击「编辑」可修改
3. 点击「添加」创建新的预设
4. 填写标签名称、录入快捷键、输入要粘贴的文本
5. 点击保存
6. 关闭窗口 → 自动最小化到系统托盘，后台运行
7. 在任何窗口（浏览器、聊天软件、编辑器……）按你设置的快捷键 → 文本自动粘贴

## 界面说明

### 主窗口

| 区域 | 说明 |
|------|------|
| 预设列表 | 显示所有已创建的快捷键预设，包含标签、快捷键、启用状态 |
| 添加按钮 | 新建一条预设 |
| 编辑按钮 | 修改选中的预设 |
| 删除按钮 | 删除选中的预设 |
| 启用/禁用 | 切换某条预设是否生效 |
| 状态栏 | 显示当前已注册的热键数量 |

### 添加/编辑预设对话框

| 字段 | 说明 |
|------|------|
| 标签名称 | 给这条预设起个名字，方便管理（如「邮箱」「问候语」） |
| 快捷键 | 点击「录入」按钮后按下你想要的组合键，自动捕获 |
| 文本内容 | 要粘贴的具体文字，支持多行文本 |
| 启用 | 取消勾选可暂时禁用此预设，不删数据 |

### 快捷键录入

1. 点击「录入」按钮
2. 按下组合键（如 `Ctrl+Alt+G`），按键会自动填入
3. 录入完成后自动停止

支持的修饰键：`Ctrl`、`Alt`、`Shift`、`Win`，可任意组合。

> ⚠️ 避免使用与系统或常用软件冲突的快捷键（如 `Ctrl+C`、`Alt+F4`）。推荐使用 `Ctrl+Alt+` 组合。

## 系统托盘

关闭主窗口时，程序不会退出，而是最小化到系统托盘（右下角图标）。

| 操作 | 效果 |
|------|------|
| 单击托盘图标 | 显示主窗口 |
| 右键托盘图标 | 弹出菜单 |
| 菜单 - 显示窗口 | 显示主窗口 |
| 菜单 - 退出 | 彻底退出程序 |

## 使用场景举例

| 场景 | 快捷键 | 预设内容 |
|------|--------|----------|
| 快速输入邮箱 | `Ctrl+Alt+E` | `myname@example.com` |
| 客服常用回复 | `Ctrl+Alt+R` | `您好，感谢您的反馈，我们会尽快处理。` |
| 常用代码片段 | `Ctrl+Alt+1` | `console.log("debug:", );` |
| 地址信息 | `Ctrl+Alt+A` | 多行地址文本 |

## 常见问题

### Q: 按快捷键后没有反应？

- 确认程序在托盘中运行（右下角有图标）
- 确认该预设处于「启用」状态
- 确认快捷键没有与其他软件冲突
- 尝试使用 `Ctrl+Alt+` 开头的组合键

### Q: 粘贴出来的内容是旧的？

- 程序会自动恢复你之前的剪贴板内容，如果粘贴速度太快可能来不及
- 关闭其他剪贴板管理工具（如 Ditto、Snipaste）后重试

### Q: 开机自动启动？

- 右键 `QuickPaste.exe` → 创建快捷方式
- 按 `Win+R`，输入 `shell:startup`，回车
- 把快捷方式粘贴到打开的文件夹里

### Q: 配置文件在哪里？

- 配置文件 `presets.json` 和 exe 在同一目录下
- 可以手动编辑 JSON 文件来批量管理预设
- 格式示例：
```json
[
  {
    "id": "1",
    "label": "邮箱",
    "hotkey": "ctrl+alt+e",
    "text": "myname@example.com",
    "enabled": true
  }
]
```

## 系统要求

- Windows 10/11
- 无需安装 Python 或任何依赖，双击 exe 即可运行
