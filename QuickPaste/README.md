# QuickPaste 🚀

快捷粘贴工具 — 全局热键触发预设文本粘贴，支持自定义快捷键、多组内容、图形界面、托盘最小化。

## 功能

- 🔥 **全局热键** — 任意组合键触发，支持多组快捷键
- 📝 **自定义内容** — 图形界面编辑预设文本
- 📋 **智能粘贴** — 写入剪贴板 + 模拟 Ctrl+V，完美支持中文
- 🖥️ **托盘最小化** — 点 X 缩到系统托盘，后台运行
- 📦 **单文件 exe** — PyInstaller 打包，无需 Python 环境

## 使用

1. 运行 `QuickPaste.exe`
2. 在界面中添加/编辑预设文本和对应快捷键
3. 最小化到托盘
4. 在任何窗口按快捷键即可粘贴预设内容

## 开发

```bash
pip install -r requirements.txt
python main.py
```

## 打包

```bash
build.bat
```
