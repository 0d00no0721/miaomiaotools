# who_are_you — 知乎"查成分"工具

## 这是什么

给一个知乎用户"查成分"：采集其公开数据（主页简介、回答列表、最高赞回答、子夜极光是否关注），分析政治/经济/文化三维左右倾向，生成词云图，输出单文件 HTML 报告。

## 快速使用（双击即用）

### 首次安装（一次性）

1. **安装 Python 依赖**：
   ```
   pip install -r requirements.txt
   ```

2. **安装油猴脚本**：
   - 确保 Edge 已安装"篡改猴"(Tampermonkey) 扩展
   - 打开篡改猴管理面板 → 新建脚本 → 把 `zhihu-chemfen.user.js` 的内容粘贴进去 → 保存

3. **加载 BrowserSkill 扩展**（如果还没加载过）：
   - 参见 BrowserSkill 文档，将扩展路径填入 `config.json` 的 `bsk_path` / `bsk_home`

### 日常使用

1. **双击 `run.bat`** — 它会自动启动 bsk 守护进程 + Edge + 本地分析服务
2. **在 Edge 里打开任意知乎用户的主页**
3. **点击页面右下角的"🔍 查成分"按钮**
4. **等待 2-5 分钟**，分析完成后会弹出通知和报告链接
5. **点击报告链接**，在浏览器里查看 HTML 报告

> 也可以不用油猴脚本，直接命令行运行：
> ```
> set PYTHONIOENCODING=utf-8
> python main.py "https://www.zhihu.com/people/某用户" --answers 600 --top 1
> ```

## 命令行参数

```
python main.py <用户URL或url_token> [选项]

选项：
  --answers N    最多采集回答数 (默认 600)
  --top N        读取全文的最高赞回答数 (默认 1)
  --no-llm       不调用 LLM, 只采集+词云
  --reuse-data   复用已采集的数据 (不启动浏览器)
  --out PATH     报告输出路径
```

## 文件

| 文件 | 角色 |
|------|------|
| `run.bat` | **双击启动器**：启动 bsk + Edge + 本地服务 |
| `server.py` | 本地 HTTP 服务 (127.0.0.1:9588)，接收油猴脚本请求 |
| `zhihu-chemfen.user.js` | 油猴脚本：在知乎主页添加"查成分"按钮 |
| `main.py` | 主程序：采集(bsk API) + 分析(jieba/wordcloud/LLM) + 报告生成 |
| `_llm.py` | LLM 客户端（openai/anthropic 双规范） |
| `config.json` | 配置（LLM API + bsk 路径 + 特征用户） |
| `requirements.txt` | 依赖列表（jieba/wordcloud/matplotlib 等） |
| `report_<token>.html` | 生成的报告（可直接浏览器打开） |
| `data/<token>.json` | 原始采集数据（可 `--reuse-data` 复用） |

## 配置

编辑 `config.json`：
- `model` — LLM 模型名（当前 `deepseek-v4-flash-ascend`，快且无 reasoning 延迟）
- `feature_token` — 特征用户 url_token（用于判断目标用户是否关注此人，可留空）
- `bsk_path` / `bsk_home` — BrowserSkill CLI 路径
- `api_key` / `base_url` — LLM API 配置

## 工作原理

```
run.bat
  ├─ 启动 bsk daemon (BrowserSkill 守护进程)
  ├─ 启动 Edge (--load-extension 加载 BrowserSkill 扩展)
  └─ 启动 server.py (本地 HTTP 服务, 监听 9588 端口)

油猴脚本 (zhihu-chemfen.user.js)
  ├─ 在知乎用户主页显示"查成分"按钮
  └─ 点击 → GM_xmlhttpRequest → POST http://127.0.0.1:9588/analyze

server.py
  └─ 收到请求 → 调用 main.py → 返回报告路径

main.py
  ├─ bsk session start → 打开 Agent Window
  ├─ 导航到知乎用户主页 → 读取 js-initialData (简介/粉丝数)
  ├─ 导航到 /answers 页面 → fetch 知乎 API 分页采集回答列表
  ├─ 对前 30 条用单条 API 补充赞同数
  ├─ 查关注者列表 (最多 500 人) 判断子夜极光是否关注
  ├─ jieba.posseg 词性过滤 + TF-IDF 提取关键词
  ├─ wordcloud 生成词云图 (base64 内嵌)
  ├─ LLM 分析三维倾向 (deepseek-v4-flash-ascend)
  └─ 生成单文件 HTML 报告
```
