# USTC LLM 用量统计与可视化 🔍

一个 Tampermonkey 用户脚本，为 [中科大 LLM 平台](https://llm.ustc.edu.cn/) 增加用量统计与可视化面板。

## 是什么

在页面右下角添加一个 📊 悬浮按钮，点开即可查看：

- **当天统计** — 请求数、总 / 输入 / 输出 Token、缓存命中、费用（KPI 卡片）
- **图表可视化** — 按模型分层设色的柱状图、请求占比饼图、近 24 小时按半小时粒度的用量堆叠图（基于 ECharts）
- **历史累计** — 每天首次刷新时把当日快照归档到浏览器本地，形成逐日累计的柱状图 / 折线图 / 占比图
- **数据导出** — 一键导出当天或历史累计的分模型统计 CSV

## 特点

- 📦 **本地持久化** — 每日快照保存在 Tampermonkey 存储（`GM_setValue`），只存本地、不上传
- 🧩 **自动补全历史** — 会读取近三天的访问日志明细，自动补全「昨天 / 前天」的每日汇总
- 🪶 **多 CDN 兜底** — ECharts 依赖多源依次尝试加载，避免单源失效
- 🌐 **零依赖运行** — 装上就能用，无需额外配置

## 安装

1. 安装浏览器扩展 [Tampermonkey](https://www.tampermonkey.net/)
2. 新建脚本，把 `ustc-llm-usage-analytics.user.js` 的内容粘贴进去并保存
   （或直接把 `.user.js` 文件拖进 Tampermonkey 管理面板）
3. 打开 <https://llm.ustc.edu.cn/>，点击右下角 📊 按钮

## 使用

- 点 **🔄 刷新并归档**：抓取当天数据并存档
- 「当天」标签：查看今日用量
- 「历史累计」标签：查看逐日累计趋势
- **⬇ 导出 CSV**：导出当前标签页的分模型统计

> 历史数据从首次「刷新并归档」开始积累，无法找回之前未采集的记录。
